# MoeKoeMusic在线音效插件



使用在线音效，让MoeKoeMusic能使用魔法音效
# 插件

## 音效  
> 也就是xx上的变乐器功能

钢琴 | 乐器 | 尤克里里 | 唢呐 | DJ | 伴奏

~~建议使用唢呐音效，余音绕梁呀！~~

## 其他设置

**无音效自动切歌** — 当前歌曲不支持所选音效时，自动跳过并切换到下一首，最多连续跳过 5 首后暂停播放

**高潮模式（只播放高潮部分）** — 开启后获取歌曲高潮片段，跳转至高潮部分播放，片段结束后切换下一首

## 食用方法

1. 将插件加载到 MoeKoeMusic 的插件系统中（设置 → 插件 → 安装插件 → 选择此插件 → 安装即可→刷新或重启）
2. 播放器控制栏会出现插件按钮
3. 点击按钮打开音效面板，选择所需音效
4. 建议开启无音效自动切歌，喜欢听原曲高潮部分可开启高潮模式
